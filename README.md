# ماسح البطائق الذكية — Smart Card Scanner

تطبيق Android احترافي لمسح البطائق الشخصية اليمنية (eID) عبر NFC والكاميرا، مع مطابقة ذكية لقاعدة بيانات Excel.

## الميزات

- **مسح خلفية البطاقة**: قراءة MRZ (TD1) والباركود عبر الكاميرا باستخدام ML Kit
- **قراءة NFC**: قراءة شريحة eID عبر JMRTD مع دعم BAC (Basic Access Control)
- **استيراد Excel**: استيراد قاعدة بيانات كبيرة مع شريط تقدم
- **مطابقة ذكية**: مطابقة الأسماء العربية بخوارزمية متعددة المستويات
- **تصدير Excel**: تصدير جميع السجلات إلى ملف Excel منسق
- **واجهة عربية RTL**: تصميم حديث ونظيف بالعربية

## المعمارية

- **Clean Architecture + MVVM**
- **Kotlin + Jetpack Compose**
- **Hilt** للحقن
- **Room** لقاعدة البيانات
- **CameraX + ML Kit** للمسح
- **JMRTD** لقراءة NFC/ePassport
- **Apache POI** لـ Excel

## تدفق العمل

```
مسح الخلفية (MRZ) → قراءة NFC (BAC) → مطابقة القاعدة → عرض النتائج → حفظ → تصدير
```

## المتطلبات

- Android 7.0+ (API 24)
- جهاز يدعم NFC (اختياري)
- كاميرا خلفية

## البناء

```bash
./gradlew assembleDebug
```
